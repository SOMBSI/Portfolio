Projet de Licence : Mise en place d’une infrastructure cloud privée virtualisée, automatisée et supervisée

Contexte : Réalisé chez OCTAL GROUP pour centraliser et sécuriser les services informatiques.

Objectif : Déployer un cluster Proxmox, sécuriser avec pfSense, automatiser avec Ansible, superviser avec Grafana/Prometheus.

Attentes : Optimisation des ressources, sécurité renforcée, automatisation des déploiements et supervision proactive.

Architecture du projet

Schéma global de l’infrastructure : Proxmox VE, pfSense, Windows Server, Grafana, Prometheus et VLANs.

Interface Proxmox

Vue du cluster Proxmox avec les machines virtuelles déployées.

Sécurité réseau avec pfSense

Configuration des règles de filtrage VLAN et du NAT pour sécuriser les flux réseau.

Automatisation avec Ansible

Exemple de playbook Ansible utilisé pour automatiser le déploiement des services.

Supervision Grafana / Prometheus

Tableau de bord Grafana affichant les métriques du cluster et les alertes configurées via Prometheus.

Gestion des utilisateurs (AD/DHCP)

Configuration Active Directory et DHCP pour centraliser la gestion des utilisateurs et des adresses IP.

Résultat final

Infrastructure fonctionnelle : VLANs opérationnels, supervision active et services déployés avec succès.
